# Volume Profile Trading Journal

## Purpose

Define a future manual-review journal format.

## Fields

- Date
- Venue
- Symbol
- Timeframe
- Setup type
- Profile scope
- POC
- VAH
- VAL
- VWAP context
- L2 context
- Reason for interest
- Acceptance result
- Follow-through result
- Screenshot reference
- Mistake category
- Lesson

## Journal Use

The journal should be used for manual chart review before any strategy activation or model training.
