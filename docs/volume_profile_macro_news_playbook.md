# Volume Profile Macro News Playbook

## Purpose

Document how macro news should be handled in Volume Profile research.

## News Categories

- Central bank decisions
- Inflation data
- Employment data
- Treasury auctions
- Crypto regulatory events
- Exchange-specific incidents
- Large unlocks or protocol events

## Research Handling

- Mark news windows separately from normal profile behavior.
- Do not assume normal acceptance/rejection logic around high-impact news.
- Compare pre-news and post-news value areas.
- Track whether price returns to prior POC or establishes new value.

## Crypto Context

Crypto trades continuously, so macro events can interrupt any session. UTC daily reset may not align with the user's local planning clock.

## Constraint

No news execution logic is implemented. This is documentation for future review and labeling only.
