# Volume Profile Common Mistakes

## Mistakes

- Treating every POC as a trade level.
- Trading first touch of a prior high or low without confirmation.
- Ignoring whether price is accepting or rejecting value.
- Confusing a broad rejection detector with a high-quality reversal setup.
- Treating latest L2 context as historical L2 replay.
- Ignoring spread and liquidity.
- Optimizing setup rules before fixing labels.
- Combining correlated instruments as if exposure were diversified.
- Treating passive follow-through as executed PnL.

## Current Guardrails

- Research-only setup studies.
- No paper/live trading.
- No ML.
- No execution activation.
- Separate features and labels from strategy logic.
