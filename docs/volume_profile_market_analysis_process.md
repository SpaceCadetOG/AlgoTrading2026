# Volume Profile Market Analysis Process

## A To Z Process

1. Identify broader profile scope: daily, rolling 3d, rolling 7d, composite 30d.
2. Mark POC, VAH, VAL, HVNs, and LVNs.
3. Classify profile shape.
4. Check VWAP distance, slope, and regime.
5. Review price action: aggression, sideways action, initiation, rejection, failed auction.
6. Add L2 context: spread, depth, imbalance, liquidity near VWAP.
7. Compare setup family: accumulation, trend, rejection, reversal.
8. Review feature/label export before considering model work.

## Questions

- Is price accepting inside value or rejecting value?
- Is the current profile balanced or directional?
- Is VWAP aligned or conflicting?
- Is L2 pressure descriptive or unavailable historically?
- Is the setup label favorable, accepted, rejected, or mixed?
